DEPLOY AS YOUR OWN APP
This is a prototype running in Claude.ai. To run this as a real production app with automated daily emails, you have three options below — ranging from no-code to developer.
OPTION 1 — Easiest: Replit (No Code)
Replit is a browser-based coding environment. You can deploy this as a live web app in under 10 minutes with zero coding knowledge.
1. Go to replit.com → Create account (free)
2. New Repl → HTML/CSS/JS template
3. Paste this entire HTML file into index.html
4. Add your Anthropic API key as a Secret named ANTHROPIC_API_KEY
5. Click Run — your app is live at a public URL
6. For daily emails: add a cron job in Replit that hits a /send-daily endpoint at 6am
OPTION 2 — Best: Vercel + Resend (Free Tier)
Vercel hosts your app for free. Resend sends transactional emails for free (up to 100/day). This gives you real automated daily emails every morning.
1. vercel.com → New project → paste code into Next.js template
2. resend.com → Get free API key
3. Add environment variables: ANTHROPIC_API_KEY + RESEND_API_KEY + YOUR_EMAIL
4. Create a Vercel Cron Job (vercel.json) to trigger /api/daily-email at 6:00 AM
5. The cron job generates today's plan with Claude → sends via Resend → arrives in your inbox every morning
6. Ask Claude to build the full Next.js version of this app — it can write all the API routes and cron config for you
OPTION 3 — No Deploy: iOS Shortcut
If you just want automated daily emails without any deployment, use the iOS Shortcuts app to call the Claude API each morning and email you the result.
1. Open Shortcuts app on iPhone → New Shortcut
2. Add action: "Get contents of URL" → api.anthropic.com/v1/messages
3. Method: POST, Headers: x-api-key + content-type, Body: your daily prompt JSON
4. Add action: "Send Email" → parse Claude response → send to yourself
5. Set automation: Run at 6:00 AM daily
6. Ask Claude to write the exact Shortcut configuration for you
Recommended path: Start with Option 3 (iOS Shortcut) to get daily emails immediately with zero setup. Then ask Claude to build the full Vercel + Resend version when you want a proper app. Claude can write every line of that code for you — just start a new conversation and say "Build me a Next.js version of my Hollywood Protocol app with Vercel cron jobs and Resend email."
